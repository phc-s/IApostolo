Olá! Sou seu microagente de IA especialista na Torah. Como posso ajudar você hoje?

🛠️ Funcionamento do Agente

1. Indexação de PDFs

Carregamos e estruturamos os ficheiros oficiais em PDF da Torah diretamente no servidor.

2. Busca Semântica RAG

Ao fazer uma pergunta, o algoritmo busca exatamente as informações e versículos mais relevantes das escrituras.

3. Resposta Fundamentada

O modelo sintetiza a explicação em linguagem clara, citando expressamente as passagens desejadas pelo usuário.

🏗️ Arquitetura & Tecnologias

Construído sobre um pipeline leve de RAG (Retrieval-Augmented Generation) para garantir respostas fiéis às escrituras sem alucinações fora de contexto.

Python 3 FastAPI Google Gemini API PyPDF2 HTML5 / CSS3 JavaScript (ES6+) Marked.js
